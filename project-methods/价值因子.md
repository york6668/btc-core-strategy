# 价值因子研究指引

本文件帮助模型持续发现、评估和更新核心报告因素。市场分析以标普500、纳指100和BTC为核心；加密周期、企业利润、货币与资产重估是收益机制，不是资产分类。组合成员研究服务组合增减与成分调整，独立BTC／黄金属于额外机会。分析期限、因子随机制与证据选择，没有固定目录、数量、方向、权重或评分；示例不代替当前判断。

本文件保存可复用的研究方法，不保存当期因子列表、最新数值或另一份策略。当前采用、调整、退出的因子及原因保存在同一 `DecisionSnapshot.assessment.factor_assessment`；正式建议仍来自 `recommendations`。流程与确定性接口由 [BTC 核心策略 Skill](../skill/btc-core-strategy/SKILL.md)维护，资产事实仍只来自项目内三份事实文件。普通行情变化只更新证据和当期评估，不频繁改写本指引。

## 如何发现和评估

先独立核验公开市场变化与当前定价背离，再对照同一策略中的纯市场基线及其后有效观察、反证和成立/失效条件；市场结论和价格风险独立冻结后，才读取仓位材料并结合资产事实检查配置建议与本金保护，维护未在手机摘要展示的内容。美股使用自身行情、交易日历、盈利与估值证据，区分正常波动、实质下行和减仓后的回补依据；加密分别评估篮子、独立BTC与保护空单，区分本金成本、风险敞口和保证金。XAUT按黄金及发行托管属性研究。共同宏观因素按资产分别核验传导，不能重复累加成独立收益或风险分散。

每轮同时做两项研究判断：旧深评的依据是否仍成立；当前环境是否出现旧报告遗漏、低估或过时的重要因素。主动查验上次有效核验后的公开新增信息和下一复核前的重要事件；首次基线及深评发布前覆盖报告讨论的投资周期。重大政策决定、融资和资金流/供需变化只是发现方向，不形成固定必查名单、数量、权重或关键词评分。不能等价格突破或旧名单变化才开始发现，也不能以行情采集包代表全部研究证据。

对实际选用的因子，结合问题说明其作用机制、影响周期、当前方向与重要程度、支持和反证，以及仍不确定的部分。可以形成定性判断，不要求数值权重或统一评分。对实际发现的重要因素保留证据、公布或发生时间、传导机制、影响期、原报告是否充分覆盖及可能改变的判断；只出现名称不等于已评估。因子名称相同不代表机制相同；一次相关走势不证明因果，单一因子不能自动推导 BTC 被低估、高估或结构价值区迁移。

将环境背景、传导过程与具体资产的市场结果区分。例如资金供应扩张、融资成本下降、企业盈利改善和资金实际进入BTC是不同命题；模型需判断传导是否发生、发生在哪个市场和周期。相互关联的变量可能属于同一条因果链，不应机械累加为多份独立利好或利空。

价值背离的研究围绕报告要回答的周期形态与建议价值寻找鉴别证据：现价反映什么预期，需求、供给、融资、盈利与现价是否匹配，新增信息是否已反映或被其他因素抵消，哪种风险已经出现；不要求预测未来涨跌路径或兑现日期。历史区间提供检验位置，不能直接充当合理估值；价格未突破也不能跳过重大定价变化，短期抗跌不证明中长期价值未损。因素与历史起点随问题选取，不把当期价格、利率或固定周数写成长期开局条件。完整方法由[核心策略的价值背离与时间优势](../skill/btc-core-strategy/references/core-strategy.md#价值背离与时间优势)承载，不另建评分或策略状态。

前瞻同时按[美债机会成本与风险补偿](../skill/btc-core-strategy/references/core-strategy.md#美债机会成本与风险补偿)比较 BTC、QQQ、VOO 从当前价格出发的回报空间、兑现时间及风险，期限、基准和补偿要求由模型选择。公共持有人成本只解释有对应证据的群体供需；已回本、历史成本低或价格未破位均不能代替当前吸引力判断。完整计算口径与限制由该方法单一维护，研究结果留在当期分析。

出现新增证据、修订、关键反证或机制变化时，重审受影响的判断；未受影响部分保留真实来源、数据期与原评估时间。退出或降低重要性的原因写入当期评估说明，历史版本保留，不将旧结论抹去或改写为当时已知。

跨市场、同向交易属于模型识别渠道的示例，不是必查项目或固定证据组合。模型按各市场及周期解释支持与冲突信号为何支持某种主导判断，不能用同向数据数量投票。短周期转向、波段变化和较大周期反转分别评估；局部共振不自动升级为大周期反转。

多空分歧区作为独立风险项目持续维护，重点是已形成区域的交易状态、突破迹象、双方损失风险与后续结果。形成依据只留内部引用；放量、穿越、确认和反转不机械对应。重要迹象及时报告，逐轮核验延伸、失败、重回争夺或证据不足，退出或替代说明原因。字段与接续由 [market-state](../skill/btc-core-strategy/references/market-state.md) 单一维护。

## 可扩展的参考方向

当前重点按[动量枯竭与反向趋势](../skill/btc-core-strategy/references/core-strategy.md#动量枯竭与反向趋势)分别研究原方向推动力的衰减和相反方向趋势的持续形成，上下双向适用。驱动力、价格反应、延续性及反证须落实到实际研究，不从低值、反弹或指标共振自动推导反转；仍独立比较当前定价的风险收益和个人风险。该目标不封闭因子选择，也不新建评分或任务。

以下问题并非分类标准或任务清单，具体是否采用由模型按本次证据决定，也允许发现表外因素。

| 观察线索示例 | 可研究的问题 |
|---|---|
| 纳指100与标普500的盈利及估值变化 | 分别核验盈利修订、利润率、股东回报、估值与集中风险，区分利润增长和估值扩张；正常定投、已有持仓减仓及恢复投入的条件是否仍成立？ |
| 代币供给、价值获取与黄金权益 | BTC的稀缺性与需求如何传导；其他代币的使用、解锁和稀释是否支持持有依据；XAUT的黄金敞口、发行托管及赎回限制如何影响配置？ |
| 资金供应、信用与融资条件变化 | 可获得资金及承担风险的能力是否改变？货币存量、跨境信用和市场融资价格分别说明什么？M2、名义或实际利率、美元融资条件可按问题选用，不能互相替代。 |
| BTC 资金来源与现货交易变化 | ETF、稳定币、现货主动成交或跨所成交能否支持新增资金及其持续性？余额增加、资金迁移与实际购买如何区分？ |
| 持有者、供需与链上估值线索 | 持币成本、实现盈亏、发行或流通供给是否改变潜在买卖压力？指标口径、地址归类或内部转账是否提供另一种解释？ |
| 价格接受、相对强弱与杠杆变化 | 市场是否在不同时间和交易场所持续接受某一价格？衍生品仓位、融资或清算风险如何影响现货表现？ |
| 油价或其他重大事件冲击 | 冲击由什么推动，是否持续，能否改变融资条件、风险偏好或 BTC 资金传导？油价涨跌本身没有固定方向含义，也不是必选因子。 |

宏观研究分别核验对美股盈利与估值、加密资金供需及资产重估的传导。货币政策、增长或通胀资料仅在解释当前具体问题时按需引用，不自动扩展为独立专题；“高利率时代”也不是永久前提。

## 证据与时间

公开原始资料进入现有 `EvidenceBundle`，判断引用其真实值与来源；引用可核验不等于因果已证实。优先使用与问题相符的原始发布方、交易场所及明确口径的数据；转载或同一序列的镜像不能重复增加独立性。辅助采集仍只是待验证线索。

区分数据所属期、公布时间、取得时间和模型评估时间；慢数据不按小时行情的年龄机械失效，也不因今天重新抓取而成为新数据。模型结合实际发布节奏、修订及当前机制判断是否仍可沿用。不得固定假定 M2 领先 BTC 若干周，也不得把事后修订数据回填进历史判断。

尚未发布、证据缺失、冲突与暂时不可得应如实说明。没有支持或反证引用时可以保留受限判断或待解问题；关键来源不可得时记录具体缺口、影响和补查期限；尚未公布则研究条件情景和安排的有效期，公布后核验实际结果与传导，不预判方向。不得填零、伪造引用、把缺失写成已验证或将尚未查证解释为没有变化。是否足以形成保守完整策略仍由主任务判断。

## 周期深评与后续嗅探

主周期由投资问题、价值兑现机制与证据选择，因子的观察频率不决定报告期限。深评形成周期阶段、方向、价值和风险；小时嗅探检验支持、累计反证及即时风险。缺少周期证据先补证并说明限制，不能以最新小时信号替代；近端区域空间不作为周期收益上限，价值比较保持同期限。

| 职责 | 周期深评：Astra/max | 小时嗅探：Sol/high |
|---|---|---|
| 工作 | 确定周期、正式采纳的因子及归因、未来价值、下行路径和组合方案 | 发现和验证支持、反证、机制变化与未覆盖问题，解释预设情景进展 |
| 权限 | 只读分析并批准最终映射，不写正式状态或报告 | 核验事实及映射，唯一写入正式结论和建议，负责报告 |
| 进入方式 | 首次完整基线，或实质市场证据、机制、风险范围及深评必要复核条件成立；账户变化另作仓位适配 | 按原小时频率持续运行，以已采纳深评真实时间累计 |

因子可自由发现和退出，不因目录缺项或单个波动机械重评。对与当前策略实质相关的重大事件遗漏按严重分析缺陷处理，Sol 在 factor_checks 记录覆盖核验，以 research_findings 和 PUBLIC_RAW 引用当轮发起或恢复原 BTC_CYCLE；同一问题不重复建研究。待修正状态沿用既有请求和观察派生，新结果正式采纳前不能被后续平静观察清除。独立 Astra 接收原始证据和中性问题，先冻结市场评级、周期共振/反转、冲突综合判断、分歧区及价格风险，再接收本地事实完成持仓比较，最后审阅同一代理收到的映射候选。Sol 发布前对照发现核验正文：纳入说明影响，排除说明理由，未解决说明限制和复核；六项结构齐全不等于分析完整。短窗承接或去仓只是竞争解释，不能直接证明中长期价值未受损。

Astra 的报告与手机表达按市场结论与依据、价格与风险建议、个人组合应对分开。标普500、纳指100和BTC分别明确评级、周期、当前结构、较前次变化、简短依据与确认级别；小时承接、波段形态、中期趋势分别核验，未知不写中性或结构未变。市场依据不含仓位及操作，个人应对以当前已确认组合版本为单位。评级未变时，重要结构变化仍与背离及波段风险一同独立参与报告判断，不受中期未反转、仓位未变或当天已报告屏蔽。内部分析过不等于用户已收到，去重对照真实展示。研究、正式发布、实际回读和自然小时验收分别确认。

## 参考资料

这些资料用于确认指标口径与解释边界，不组成固定数据源或必查清单。

- [BIS 全球流动性指标](https://data.bis.org/topics/GLI/tables-and-dashboards)：从跨境及外币信用观察流动性，不能当作各国 M2 的简单总和。
- [美联储 H.6 说明](https://www.federalreserve.gov/releases/h6/about.htm)：确认美国货币供应统计的口径与月度发布安排。
- [芝加哥联储金融条件指数](https://www.chicagofed.org/research/data/nfci/current-data)：金融条件可结合风险、信用与杠杆观察，不能由单一政策利率代替。
- [EIA 原油价格影响因素](https://www.eia.gov/finance/markets/crudeoil/)：结合供需、库存及金融市场研究油价变化，而不是固定赋予涨跌含义。

市场事实、历史假设与个人事实分开；完整研究先冻结市场结果，再形成整体配置决定。配置正文只交付最终安排和执行限制。研究时间窗口、判断期限、预期兑现窗口分别维护，累计反证或前瞻落空应复核对应研究；不能靠滚动报告日期延续预测。具体阶段与字段由核心 Skill 的 references/closed-loop.md 统一维护。
