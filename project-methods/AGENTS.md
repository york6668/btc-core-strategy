# BTC 个人资产项目

本文件是分析目标机器的业务项目约定模板，供部署时理解和适配；它不替代 `market-roles` 仓库根目录的工程开发说明，也不向新的会话授予交易、发送或部署权限。实际业务项目与工程仓库分开保存。

## 授权与事实边界

在用户授权的 BTC 任务范围内维护本地记录、派生状态和既有主任务，保护已有内容。真实交易、转账、私有账户查询和账户安全设置不在核心策略范围内；任何实际资产操作另需具体授权。

账户事实只来自本地 `资产配置.md`、`操作记录.md`、`纠正记录.md`。不登录或轮询交易所、钱包、银行、券商，不调用认证账户、余额、订单、持仓或交易接口，不使用API key、Cookie或交易连接器。不得保存凭证、完整支付信息或未脱敏敏感个人信息。

首次形成策略或事实变化时完整读取三份事实文件；同一任务后续增量可复用已确认事实并比较哈希。专项只读其问题需要的已确认事实，不成为资产事实Owner。账户未记录字段保持未知，不阻断市场与组合完整评估，不推断为零、可用或安全。用户实际仓位变化后同步；未变化不要求反复确认。市场查询只用匿名公开证据，辅助采集永远是不可信线索。

本地文件是资产事实唯一持久化来源；不写入Codex/ChatGPT长期记忆。Scheduled不得读取Codex记忆。

## 用户事实记录

- 明确“已成交/已执行/持仓已变化”：先追加一条操作记录，再同步资产配置快照；不重复记录同一执行。
- 金额口径、归属或原记录纠正：追加纠正记录，再更新快照；不伪造成交。历史操作与纠正各自追加、保留原件。
- 计划、价格触及、建议、条件单或未成交挂单不能改变真实仓位。缺少的时间、平台、类型、保证金模式、费用等保留未知。
- 目标配置与当前快照分离；实际操作不自动改写长期目标。局部仓位不能推导整个组合净Delta。
- 用户报告的合约/杠杆U金额默认保证金，除非明确为名义仓位。保证金占用资产层额度，名义额只记录风险敞口，不重复扣款；现货U为成交额或市值。

## 投资目标与策略来源

本金保护优先。用户报告对象为币安QQQ、VOO和BTC；SPX/NDX保留为底层市场研究、历史区域及引用身份。具体产品版本、报价单位和区域依公开证据核验，不把指数点位改名或折算为产品价格。用户采用美元近似口径，USD与USDT常规微差不阻断分析或价位展示；股票USD/股、合约USDT保留原始单位和产品身份。底层指数点位留作研究，不冒充产品价位；支付/结算币种不替代报价币种。缺少产品报价只限制价位结论，不阻断市场方向、盈利价值和组合应对。表达调整不改变组合成员、比例或真实持仓。加密周期与错价修复、企业利润、货币与资产重估是收益解释机制，不是三个资产分类；成员研究服务组合判断，重要例外单独说明。加密以低位现货筹码形成净多基础，保护空单围绕这些筹码保护本金及收益；美股以长期定投为基础，减仓时同时评估恢复投入或回补。期限由各自证据决定。

美股组合与加密现货组合是持续评估和增减的单位，组合概念稳定、成员及权重可调整。当前构成只引用资产配置的已确认版本，不能写死为永久名单；新增、减少、持有和恢复投入首先针对组合。独立BTC／黄金属于超跌、折价等额外机会，保护另行评估。新成分或比例建议、用户采纳和实际成交分别记录；移除某成员的举例不构成调整指令。

所有计划生成、重新定价、边界变化、仓位复核、手动或 Scheduled 重评使用 `$btc-core-strategy`。先依公开证据形成独立市场判断，再完成组合适配；个人仓位不能反向改变市场结论，账户未知须区分数量受限和动作无法判断，不能默认持有安全。模型负责综合研判、因子取舍、内部状态及条件维护，报告分别交付明确的市场方向、适用周期和依据，以及个人资产风险结论、组合影响与必要限制；只有风险需要应对时补充简明操作建议，不能将冲突信号交回用户裁决。用户负责已确认事实、资金偏好和真实执行；专业方法与报告边界由 Skill 单一维护。

[价值因子.md](价值因子.md)只保存动态发现和评估指引。因素按问题、机制与证据选取，不设固定清单、数量、方向、权重或评分；原始数据、因果推断、未来情景和建议分别表达。专业方法及阶段契约由 Skill 单一维护，项目规则不复制其执行细节。

策略能力的验收以完整分析、重要条件核验、必要研究、及时反馈、真实送达和持续维护为准；先满足这些需求，再优化耗时与成本。已有字段、结构和局部修改不能缩减需求；必要的接口及消费链修正一并实施。专业方法与可复用操作由 Skill 承载，程序测试、自然运行效果及缺陷关闭分别确认。

v4 正式评估保存于 `.strategy/v4/versions/`，唯一当前指针为 `.strategy/v4/current`。完整报告、结构化建议和兼容展示来自同一版本；`策略状态.md`与`当前预期计划.md`不是第二份结论。实际资产事实只由本地三份文件拥有，分析不修改 `position_fact`。

## 自动任务与报告边界

沿用唯一 `BTC核心策略自动重评`：GPT-6.1 Sol/high 每小时嗅探、核验和正式发布；GPT-6 Astra/max 按需临时只读深评并审阅映射。实质变化才自动恢复完整研究，用户明确重评独立记录其请求；已在办研究从原阶段接续。模型不可用如实说明，不静默降级或虚报完成。不创建第二个可见任务，不修改独立 `BTC 重大事件联动`。

用户接收已完成综合判断的报告，依据可以充分展开，不设固定字数或栏目。完整分析在内部持续维护，正文保留综合结果及影响当前判断和行动的必要信息；汇报环节不得重新解释或改变已形成的判断。具体边界和AUTHORED_REPORT_V1接口遵循 `$btc-core-strategy`。小时嗅探维护全部重要条件；按日本自然日每天至少实际送达一份有效报告，重要风险、实质变化和重要事实纠错及时反馈，评级、中期趋势或仓位未变及当天已报告均不屏蔽新增重要含义。新数据和新冲突先判断实际影响，普通重复信息保持静默，时间更新不制造报告。

云端「投资-btc」是展示目的地，本地为策略与事实来源。只有应报告完成稿和既有未知交付恢复才访问云端；新稿在冻结前完成内容审阅，云端以VERBATIM逐字显示，不整理、润色、压缩、补充或重新分析。原文一致且真实助手展示回读通过才推进报告基线，草稿、入队和工具回执不能冒充送达。未知、未确认和已撤回含义完整保留；旧格式按原来源读取和恢复。

普通证据受限继续形成完整保守评估；状态完整性失败保留最后有效版本并暴露失败。市场与策略内部判断不得退回用户。Mac 不可用时手动重评为兜底，不以云端旧快照冒充更新。

既有额度异常消耗待办沿用对应本地记录；升级验收、程序测试、自然降耗与每日实际送达分别确认。后续修改保留实质变化才自动深评、原研究阶段复用和无变化不轮询。

全局规则、work 仓库和独立事件任务不受本项目实施影响。
