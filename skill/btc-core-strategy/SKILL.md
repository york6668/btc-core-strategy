# BTC 核心策略

研究、规划与报告共同遵守[事实、判断与规划前提](references/core-strategy.md#事实、判断与规划前提)：用可核验的核心证据链支持当前结论，区分事实、受限判断与待验假设；未证实假设不能成为无条件规划前提。条件情景须有可观察支持和失效依据，报告压缩保留决定性口径、时间、反证与限制。程序保障引用和状态，模型裁决证据，不增加评分器或固定指标清单。

报告以框架识别的当前周期状态（中性／向上／向下）、价值与风险为主线，周期不是天数或周数。重点分别核验原方向推动力是否衰减、相反方向是否建立可持续趋势；上下两个方向均适用，动量枯竭和短暂反弹不直接等于反转。观察窗口、判断有效期和兑现窗口由问题、机制与证据另行维护，不能用延长预测期限代替周期答案。依据不足说明具体哪项判断未成立，不把未知写成中性。完整方法见[动量枯竭与反向趋势](references/core-strategy.md#动量枯竭与反向趋势)与[周期形态与下行方案](references/core-strategy.md#周期形态与下行方案)，专项验收按问题使用锁定真实数据复测或必要的实际运行证据，见原定时任务的[运行维护](references/runtime-maintenance.md#周期报告纠偏的持续验收)。

能力以完整分析、重要条件核验、必要研究、及时反馈、真实送达和持续维护验收，先满足这些需求，再优化成本和耗时。现有字段、结构、最小改动和复用偏好不能缩减需求；发现表达或执行缺口时修正对应接口及消费者。模型承担证据取舍与综合判断，报告明确呈现已形成的方向、适用周期、依据和个人应对，不能把冲突信号交回用户裁决。完整分析与报告完整的边界统一见[研判与报告的职责边界](references/mobile-report.md#研判与报告的职责边界)，研究、嗅探和报告阶段均适用；正文依据展开到足以解释主导判断，每段都应帮助理解方向、关键依据或行动；个人资产部分围绕周期主线和当前定价，交付参与、防守、等待的有据取舍、现货与空单含义、组合影响及必要限制；只有风险动作本身需要应对且有依据时才附加该动作，不能把全部建议限定为风险触发；总资金和占用比只是可选依据，不固化公式或自动调仓。完整核验和维护留在内部，成稿承接已形成的结果，不再注入完整研究指令或另作因子排序及解释。程序负责证据绑定、校验与恢复，不重排或追加正文；方法路径、字段齐全和测试通过都不证明分析已完成。

市场输入和仓位输入分阶段提供，先冻结独立市场结果，再进行个人适配；账户变化不使市场周期失效。revision 7 的完整闭环、独立风险评估与可选应对、分项复核和兼容要求见[完整闭环](references/closed-loop.md)；原市场字段及接续见[独立市场与分歧区](references/market-state.md)。模型内部完整维护周期关系、分歧区及双向风险，报告按其对综合判断和安排的实际影响表达。用户报告对象为币安QQQ、VOO与BTC，SPX/NDX保留为底层市场研究和历史引用；[产品身份及报价](references/equity-products.md)用对应公开证据核验，不能用指数点位冒充产品价格。用户采用美元近似口径，USD与USDT常规微差不阻断分析或价位展示，保留股票USD/股、合约USDT的原始单位和产品身份；底层指数点位留在研究材料。三标的采集输入及适用性见[辅助采集消费](references/collector-evidence.md)。方向、周期、结构变化、共振或反转、依据和必要限制在研判中明确对象与确认程度，未知不写中性，市场依据不得含个人仓位或操作。美股组合与加密现货组合是持续建议单位，成分和权重采用本地当前已确认版本并可调整；独立BTC／黄金是额外机会，保护另行评估。加密周期与错价修复、企业利润、货币与资产重估是收益解释机制，不是三个资产分类。本金保护优先；加密现货净多与保护配合，美股长期定投。投资原则和分析方法由[核心策略](references/core-strategy.md)维护，当前结论由 `.strategy/v4/current` 指向的 DecisionSnapshot 拥有。

`gpt-6-astra/max` 独立研究、直接撰写完整中文报告并审阅映射；`gpt-6.1-sol/high` 取证、嗅探、编排、核验、唯一正式写入和报告。模型来源按真实运行记录，型号不可用时暴露异常，不静默降级。研究完成、正式采纳、观察完成和实际送达分别确认。

## 固定本轮版本

先按[版本与节点入口](references/releases.md)固定本轮物理发布目录；脚本、Skill、方法与价值因子来自该版本。节点配置由 `BTC_NODE_CONFIG` 指定，数据保持原目录。研究通常沿原上下文版本；仅已确认程序缺陷可按该入口显式登记兼容修复，在后继恢复运行固定指定版本。UNKNOWN 投递继续原上下文版本。

## 研究与恢复

每轮沿[前瞻复核主线](references/core-strategy.md#前瞻复核主线)比较有效基线、新增及累积证据、因果与当前定价、下一验证；分别判断增量影响、原论点有效性和当前价格出发的风险收益。重要条件完整维护，方法按问题展开，不把固定模块、论点数量、窗口或报告篇幅当作必填清单。

前瞻包含[美债机会成本与风险补偿](references/core-strategy.md#美债机会成本与风险补偿)：模型按证据选择期限、基准和补偿要求，先形成情景再计算现价出发的回报，评估投资吸引力及新增风险。公共持有人成本可用于群体供需分析，不能代替当前价格、未来价值或用户个人成本；缺乏量化依据时保留具体限制。

- 首次缺少完整基线、实质反证、关键机制/风险范围变化、重大遗漏或原市场判断失去支持时，发起或恢复稳定的 `BTC_CYCLE`。普通新小时、时间到期与资料尚未公布只要求实际核验，不能冒充新研究理由。
- 用户明确要求完整重评时用 `USER_REQUESTED_REVIEW` 和真实 `user_request` 引用；同一请求复用原研究。此入口不增加 Scheduled 的自动触发条件。具体接口在运行入口与v4契约。
- 先读 `research.issues[].latest_request.progress` 及同级 completed_result、adopted_result、pending_candidates，核对原代理及实际请求，从已完成阶段接续。已采纳结果不会被较晚草稿覆盖；未处理草稿不自动重开完成研究，新请求独立判断。`NOT_CHECKED` 和归档记录不证明代理存活；旧请求结果不代表新请求完成。研究仍运行时，其他小时完成必要嗅探和报告判断后结束，不持续等待、催办或另派研究。
- 新研究只派生一个临时只读 Astra/max，`fork_turns=none`。先给受控公开原始证据、明确标注日期的市场历史锚及中性问题，不传 Sol 当前候选、嗅探判断或个人持仓偏好。同一代理先给出市场结论与价格风险，再接收本地事实完成个人应对；不因持仓改写市场判断。新公开结果先按 revision 7 登记冻结，个人阶段形成风险结论与必要建议而不改写市场正文；完整报告完成后，Sol 映射并向同一代理披露候选。
- 同一研究的补证、映射及审阅继续原阶段；带有历史个人输入或候选的旧代理不能被重新标作全新独立研究。单轮输入读取校验只证明该轮读取，不证明整个会话没有先前输入；按实际研究请求和运行来源区分独立建立与续研。
- 同一 Astra 核验具体候选和证据、反证、未决及复核条件；正文或市场含义需要改变时由它修正并重新审阅。Sol 原文承接到 `conclusion.narrative`，最终 JSON 以 `report_narrative` 或既有候选正文的 `report_hash` 绑定同一实际正文；后者避免映射复核时重复输出全文，接口见 v4 契约。结构和身份校验不能替代内容审阅。
- 未决缺陷持续保留至正式修正采纳；未获批准不发布为新周期方案，已撤回价位不从历史回填。本轮市场核验、分歧区状态与突破迹象使用 MARKET_UPDATE，已核验的重要背离或波段风险仍可走 URGENT_RISK 反馈，不以中期反转、仓位变化或当日未报告为前提；新正式价位及个人配置仍须原 Astra 审阅、Sol 采纳；仅个人事实变化可复用有效公开冻结及原请求，不重跑整个市场研究。仍有效部分继续保留；建议到期、适用性核验到期和研究触发分别处理。

BTC 回踩后的卖压与需求研判，以及持续下跌、筑底等相关问题，按[卖方衰竭场景方法](references/seller-exhaustion.md)选用日级指数和组成项。来源原值与复算口径分别解释，日值未覆盖本次回踩时仅作此前背景；新数值不机械触发深评。涉及原论点的历史修订须用当前及旧冻结引用比较组成项，解释判断影响；不能以旧批次或通用限制代替本轮研判。

## 运行与实际验收

节点启用 Docker 后，每轮同时按[持续分析契约](references/continuous-analysis.md)读取返回的 continuous-public；独立市场冻结后再读 continuous-personal。通过 BTC MCP 或 `btc-core data` 接续所有有效对象和未决条件，维护未出现在报告中的对象，提交实际复核并保留原期限、事实版本及未知。新增数据层不改变研究模型、市场优先顺序或真实发送协议。

生产使用 `$BTC_PYTHON` 和 `scripts/strategy_v4.py`。 精确承接使用固定版本 `run-value-ref` 返回的摘要，引用类型按本轮 vocabulary 填写；准备失败按运行入口显式复用冻结输入，不重新采集或自动重绑冲突。按运行入口执行 `run-prepare`，新入口 revision 7 先 market 再 observe；市场填写先用 `--stage market --check-only` 导出实际候选，再执行返回的 `review_read`（`run-read --run <run.json> --read-set <read_set.market_review> --cursor 0`），按 `next_cursor` 读取至 `complete`。每次工具输出预算采用返回的推荐值；若截断，在同一 cursor 减小 `--max-characters` 重读，不能仅打印摘要或解析文件后称读完。精确相同内容用指针去重，不借用原判断；完整理解后实际审阅，再以 `--input <market_candidate>` 冻结同一内容。输出 complete 仅表示材料输出完毕，不能写判断后同次调用直接冻结；分阶段 `run-advance --template <原模板> --answers <本轮判断JSON>`；旧 --input 完整稿兼容。只写判断及受影响内容，原始引用和已写源稿的精确承接由程序完成，接口见运行入口。`run-material` 默认只提供报告必要性材料；主评估用 `--stage main`，决定报告后用 `--stage report-body`。研究或绑定变化只刷新并复核受影响部分，失效模板不静默重绑；映射与正式写入使用同一校验的无写入预检。

周期证据主线按[事实、判断与规划前提](references/core-strategy.md#事实、判断与规划前提)维护：机制的应有响应、实际响应与留存、竞争解释及反证裁决接到现价价值和个人选择。方向、归因、延续和参与价值分别由自身证据支持；尺度由投资问题及完整结构决定，不按窗口长短定权。个人建议承接同一论证，账户缺口按依赖关系限制数量或动作，内部到期触发实质复核，保留旧期限与原研究身份。

验收沿真实材料进入研究、独立报告、映射批准、正式采纳、后续嗅探和实际报告逐段检查；指出具体输入输出如何支持判断，无法观察的环节保留未验证。程序测试仅证明接口与恢复行为。方法升级后的完整重评继续原研究与当前指针，不另建策略或常驻代理。

如原节点存在尚未关闭的额度异常消耗待办，沿用恢复后的本地缺陷记录；方法验收不自动关闭该缺陷。每轮先用 `run_usage.py --status --defect <原缺陷路径>` 只读检查上一完整日本自然日是否仍待统计或质量核验；仅有待办时读[运行维护](references/runtime-maintenance.md)。工程测试、三日自然运行、分析质量及真实送达分别验收。自动任务 memory 仅保留公开市场接续、研究/交付阶段与引用、待办状态和历史入口，不含账户事实、成本、目标比例、保护规模或个人建议正文。个人细节在市场冻结后的仓位阶段读取本地材料；不逐小时追加流水账，不默认读取归档历史。

## 事实、权限与反馈边界

- 账户事实只来自项目内 `资产配置.md`、`操作记录.md`、`纠正记录.md`。首次研究或事实变化完整读取；同任务未变化可复用。未知实时字段保持未知，仍完成有边界的市场与组合评估。
- 目标、建议、价格触及和观察不能改变 `position_fact`。用户拥有真实资产事实、资金偏好及执行决定；本 Skill 不查询私有账户、不使用凭证、不执行交易或形成下单载荷。
- 小时嗅探验证完整报告的全部重要条件，包括手机未显示部分。按日本自然日每天至少实际送达一份有效报告，时机由模型判断；普通噪声和同义内容保持静默，重要变化及时反馈。证据缺失、运行失败和未知投递不能计作行情静默。
- 手机以AUTHORED_REPORT_V1.body提交完成稿，遵守[研判与报告的职责边界](references/mobile-report.md#研判与报告的职责边界)，不设固定篇幅、栏目或因子清单。正文先给综合结果，必要限制直接说明实际影响，按内容使用清楚的阅读层次。冻结前逐段逐句删并重复、过程噪音和无关规则说明，详细理由集中表达，总裁决、主题选择与最后收束可作有功能的概括，核对关键依据、重要风险及未决动作影响仍准确；段落主题重要、预览清晰或自审通过不证明自然报告达标。内部维护字段不成为必备结尾，例行复核按时或提前完成及下一运行时点留在维护，失约和建议失效仍说明影响与补救。评级未变但风险含义有重要变化仍独立判断报告；云端VERBATIM原文展示，真实展示回读通过才算送达，实际正文质量另行核验。
