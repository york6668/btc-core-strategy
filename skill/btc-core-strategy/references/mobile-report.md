# 综合研判报告与原文交付

共同定义、当时可知证据、判断生命周期与分层验收统一按[判断生命周期与术语契约](decision-lifecycle.md)；本文件承接其对应阶段，不另设相冲突术语或固定指标阈值。

新稿使用 `AUTHORED_REPORT_V1`。模型先完成正式研究、本轮公开市场观察及个人适配中的综合判断，再用 `body` 表达已经形成的结果；程序校验来源、数值、单位、期限及建议有效性，返回同一正文。本文件统一维护研判与用户报告的职责边界；研究方法由[核心策略](core-strategy.md)拥有，报告必要性见[报告复核](report-care.md)。

下文的个人总体取舍与分项均须内部完整审阅，不表示每份市场更新都固定复述个人段落。正文以资产结构、早期迹象、验证及改变判断的条件为主体；个人事实或安排有新增、变化或实质影响时再交付，已实际告知且未改变的限制不重复占据正文。长期目标与当前事实分别承接；删并重复内容不解除旧建议失效、重要风险和首次事实纠错的交付义务。

## 研判与报告的职责边界

持续识别当前周期的主因果链，并检验它在本轮是否仍主导：原论点与机制、决定性事实及价格结构效果、重要反证的裁决、现价参与价值、个人取舍依次衔接。证据权重由因果和定价影响决定，不由新鲜度、风险字段或短涨跌决定；主线、噪音归属和识别条件均须随真实数据重新判断，不固定宏观、净需求、ETF或指标表。突破后的动能变化、费率等只是可选线索，不能单信号机械判反转。原论点受到独立持续反证时解释为何削弱、失效或让位；条件新增、修改及退休保留本轮依据和原因，不事后换标准。

正文开头分别承接当前周期状态（中性／向上／向下）、已形成的有界未来竞争路径及相对把握，主导依据说明为何，随后交付公开现价价值、策略适用性、重要风险与个人取舍；周期不是天数或周数。观察窗口和有效期限只服务对应判断。日内数据在实质影响这些含义时进入正文，普通反弹、回收、破位及短线剩余期限不能挤占主结论。重大即时风险仍及时报告并说明影响范围。周期分析缺失时回到原研究修正，不能在成稿时延长预测窗口。

当前方向与日期用途分别表达：机制检验期到某日，不应缩写为该状态将延续到某日。需要提及日期时，按原结果说明它是检验、有效还是兑现窗口；可以自然分句或在句内交代用途，不规定固定句式，不要求展示全部内部期限。有依据的前瞻延续判断仍按原条件、期限和确认程度表达，不能一律降为观察窗口，也不禁用“至”等字词。源稿措辞含混时对照当前结构、依据和 `forward` 的时间依据澄清，忠实承接含义不等于照搬歧义；实质判断不明则回原研究，已发送历史不改写。

承接已形成的动量与趋势判断，清楚回答当前到哪一步、依据、相较上次的实质变化与下一项鉴别性验证。原方向动力减弱、相反趋势形成和反转失败保持确认差别；短暂反弹不升级为趋势，具体证据缺口不改写成中性。只表达实际研究结果，不新增推断或机械栏目；价格风险收益、等待价值和个人风险仍保留各自结论。缺分析返回原研判，不能靠补上“枯竭／反转”等词语补齐。

完整分析由模型持有并持续维护：核验证据、去除重复支持、选择与权衡因子、比较竞争解释、判断周期关系，并裁决反证和未知对结论的实际影响。完整报告向用户交付主线、决定性依据及反证裁决、现价参与价值和个人具体取舍；不另组织一份风险变化报告。内部分析覆盖范围不等于正文必展示清单。既有 factor_assessment、outlook、研究结果与 maintenance 继续承载完整依据、未决问题及复核条件，新稿通过[revision 8 完整投资决策闭环](closed-loop.md)的最终结果接口消费研究与总体取舍，完整分析保留内部。

报告开头交付独立公开总裁决，重要市场主题说明方向、支持程度、同尺度拐点、主证据链、公开现价价值和改变条件；随后把这些前提单向映射到个人参与、防守、等待或不做的选择。总体个人安排有自己的适用范围，不能合成或回写市场总裁决；收束时同样保留这一区别。概览、理由和收束各有作用，不固定条数、栏目或句式，允许忠实改写冻结命题而非整段照抄内部摘要。方向句、主题齐全或条件清单不能代替实际个人取舍；动作确实未决时说明哪项缺口使什么决定未决。解释决定性依据如何支持这些取舍。不同周期的关系先由模型判断清楚，实际影响当前决策时再呈现；不能并列冲突信号或只写“尚未证伪”“仍有冲突”“等待确认”，让用户重新完成因子取舍。明确表达自己的判断不等于保证未来结果，也不允许把 PARTIAL、UNKNOWN 或未确认事实改写成已确认；证据不足的具体范围及其影响由模型判断，仍给出有依据的方向与有边界的安排。

依据展开到足以解释主导判断，每段及段内每句话都应帮助理解方向、关键依据或行动。重要反证进入正文时，直接说明它为何改变或没有改变当前判断；条件、未知、数据时点和产品限制用它对方向、风险、数量或行动的具体影响表达。同一动作或限制的详细理由集中说明，概览与最后收束可为理解整体取舍作必要概括，不逐字重复；删并时不能删掉本轮选择或未决动作的实际影响。来源核验过程、重复否定、完整未知清单和内部调度留在研究及维护材料。涉及执行有效性、重要风险或重要事实纠错的内容必须保留，不能以去噪掩盖。条件是否成立及是否需要调整继续由模型维护；已对外承诺失约或建议失效时，简明说明实际影响和补救，不把取证、适配及运行过程展开成报告。

内部规则用于约束判断和动作，不自动成为正文。只有当前表达可能造成具体误解时，才说明相应边界；没有提出跨资产调整，就不例行附上各资产独立判断的规则。必要限制直接落到结果，例如产品资料未确认时说明无法给出可靠产品交易价，不罗列接口、历史行或核验步骤；保护风险尚未核清时说明为何暂不能决定是否调整或调整多少，不逐项抄录未知字段。上述是信息取舍方法，不是固定句式；未变化但仍会影响当前理解或执行的重要风险仍应保留。

`next_observation`、`maintenance.recheck_at`及例行运行时间属于内部接续，不是正文必备结尾。例行复核按时或提前完成只记维护，正文交付其形成的实际判断；重要市场事件的时间、建议有效期及用户明确询问的进度按实际影响说明。旧稿已对外承诺的期限继续履行，但不因曾写过就逐轮重述或新增下一时刻承诺；内部到期先重新分析，正文交付当前判断，不例行写“过期不能视为有效”。确有对外失约或旧可执行建议失效会造成误用时，简明说明实际影响与补救。

汇报不拥有第二次研判权。Sol、其他模型、程序和云端都不能为了摘要、整理、数字绑定或交付重新排列因子优先级、另立因果解释、改变方向及建议。Sol 在既有职责内先完成小时核验及适用性判断，已核验的重要市场更新和风险仍可按原接口及时报告；需要改变正式解释、周期或建议时返回原研究。成稿只表达已形成的判断及其依据，措辞整理不产生新判断；冻结后按原文交付。

新数据、新冲突或未知解除先判断对结论、风险和安排的净影响，不自动成为报告理由。实质变化、重要事实纠错及每日最低反馈沿用原规则；尚未展示但不改变这些含义的内部发现不要求向用户逐项汇报。

## 内容和表达

用户希望报告覆盖 **BTC 及拟核对的币安 QQQ、VOO 产品**，从研究与观察输入就明确目标；`report_subjects.venue=BINANCE` 只是目标场所，不证明具体产品身份已核验。SPX/NDX 保留为底层市场研究、历史记录和引用身份，不强制成为报告标题。价格采用美元近似口径，股票USD/股与合约USDT均可展示，保留实际单位和产品身份；底层指数点位仅留在研究中。具体产品身份与价格见[币安美股产品](equity-products.md)。组合仍是持续决策单位，名称调整不改变成分、比例或真实持仓。

各市场给出综合方向及适用周期，依据围绕这个判断展开。结构变化、周期共振或反转、确认程度在改变当前理解或安排时说明，不机械复制全部 horizon 字段或排列状态标签。评级未变不代表风险含义未变；缺证不写中性。不同市场的独立结论不能被合并抹平，也不要求把每个内部分析期限变成正文的一条结论。

个人资产部分围绕已形成主线和现价给参与、防守、等待的有据取舍及现货与空头各自含义；风险服务这些建议，不以风险需要应对为提供有用分析的前提。风险结论可以独立成立，总资金与占用比只是可选依据，不从短线偏弱、比例偏离或缺数直接生成操作，不重复分析，不按五模块或逐资产固定拆分，持仓不能反向改变市场结论。分歧区状态和双向风险在内部完整维护；正文按当前判断需要给出重要区域、风险及改变条件，不强制单列分歧区或逐项展开双方路径。观察区触及不自动成为交易建议，小时变化不擅自升级为中期反转。按实际内容使用加粗结论、短段、列表或表格，让市场判断和个人应对容易找到；不设固定长度、段数或栏目，版式不能代替信息取舍。预览只作表达回归样本，不固化后续方向、周期、价位或栏目模板；预览清晰不证明后续自动成稿达标。

前瞻中的价格吸引力、美债机会成本及风险补偿承接已完成研判。已形成且影响当前取舍的比较结论在正文保留：相对美债等待，现价承担新增风险的补偿是否充分或仍无法确认、主要原因及改变条件；方向偏多或偏弱、笼统的资金成本不能替代这一判断。数值或表格按理解需要展示，不固定年份、利率或溢价档位；精简计算细节时保留比较结论，不能只在内部维护中记录。情景回报、达到要求回报的门槛与预测价格保持原有区别，成本锚保留对应群体及估计属性；缺少量化依据时承接已有定性判断及影响结论的具体限制，成稿不补算或重估。若最终市场结果遗漏研究中已经形成的重要比较，先在市场阶段忠实承接并冻结，再生成正文，不让成稿阶段从因子材料重建判断。

依据日期、未完成K线、休市和正式行缺失在影响判断时保留，合并同一限制。现金、保证金等未知须区分数量限制和动作本身无法决定，不能反向改写公开市场方向，也不要求每份报告重复列出全部账户未知。如需要事实同步，只提醒实际仓位已变化时同步，未变化无需操作。

完整稿缺少重要分析时沿原研究补齐；表达缺项在本地成稿阶段修正。格式维护本身不触发完整重评。新正式建议须经原深评采纳，报告不得提高确认程度或补造价位。到期不自动延长，撤回价格不从历史恢复。

压缩必须保留决定性证据链及其边界：支撑当前结论的核心事实、模型作出的有界判断、会改变取舍的重要反证和条件不能互相替代。并列或相邻分句保留各自证据的场所、产品和比较窗口，主语切换或省略不能把多所价格的范围延伸到单所成交或持仓；前句的单所价格限定也不会自动约束后面已经换成多所的主语。可在句中共享清楚的限定，无须逐项列字段或增加固定栏目。同期变化不能被改写为已确认因果，主动成交差额不能概括为外部资金净流，历史需求不能概括为现价值得参与，低量不能改写为反转，待验情景不能变成无条件安排。并非所有限制都进入正文；删去后会扩大证据范围、提高确认程度或改变规划含义的限制必须留下。

reasoning、cycle_basis 与 deep_report_summary 对照实际原句及最终正文说明主证据和决定性限制是否保留。内部缺少核心论证时返回原研究；已有论证却在压缩时丢失则修正本地成稿。绑定正确、逐字送达及审阅字段齐全不证明内容成立；不通过关键词、固定段数或增加免责声明代替语义核验。

## 阅读验收与技术依据

报告向个人直接交付完整主题和自然段。先交付独立市场结论及方向、动量与拐点的确认差别，随后围绕主因果链选择决定性证据和关键反证，再说明权益、宏观及产品对判断的影响，之后交付个人总体取舍、必要分项与改变判断的条件。个人配置不插入独立市场总裁决。主题顺序帮助理解已形成结果，不强制段数、标题或固定资产清单。

研究摘要和个人完整叙述是冻结来源，不是逐段照抄清单。取舍时保留支持选择的证据优先级及推断边界，将同一理由集中说明；历史持仓金额核对只有纠正当前误用或直接影响决定时进入正文。数据时点在开头简明交代一次，内部生成、冻结、验收、采用、发送状态与到期续期不成为市场段落或结尾。内部时钟不代替当前价值和取舍；真实关键未知必须说明它使哪个价值比较、风险动作或数量仍不能决定，不以完整缺口详单或重复风险声明替代。

既有 bindings、quality_review、report_basis、maintenance 及研究来源承载技术依据，包含哈希、源核验、完整缺口、原检验期限和历史事实核对，不混入用户正文，也不新增另一套常驻研究或后台报告。阅读稿长度按当前用户要求和信息完整性取舍，不硬截断；没有新价量也应交付已形成的有界选择。

新稿契约5保留契约4及更早的全部有效审阅责任，四项阅读核对继续执行：decision_delivery 分别对照当前状态、有界未来路径比较及机制依据、公开价值与策略适用性、个人总体取舍的实际原句；方向句、未确认反转和条件清单不能代替前瞻。缺研究返回原研究，有限反馈准确说明完成范围；evidence_priority 对照主证据与关键反证说明取舍及范围，逐句比对产品身份状态、绑定引用与底层研究来源，不能让 SPX/NDX 的盈利判断继承币安产品标签；maintenance_separation 核对后台信息没有挤占正文且关键未知的影响仍保留；narrative_focus 核对每段推进主线，重复结论没有遮蔽个人取舍。每项都须对照最终全文与冻结命题说明实际判断，发现不足先修稿再复核，不能只填“已检查”。这是模型语义职责，程序只保护版本、审阅记录及来源，不按关键词、篇幅或规则评分。引用齐全、原生渲染通过与旧语义审查不代替本次实际阅读验收。

## 最终正文接口

现有 `cycle_basis`、`deep_report_summary` 同时核对原周期主论点、同尺度应有与实际响应和反证裁决是否在压缩中支持当前方向、拐点进展及参与价值影响；方向未变也保留有据进展或具体不足，添加枯竭字样不算完成。当前周期状态须从市场结果贯穿正文，核对主导依据是否支持该判断，以及局部价格风险是否被误当周期价值；对照实际措辞说明当前方向与日期用途是否分清，日期未变不能证明含义未变。报告只承接已形成的同期限风险补偿判断；缺少周期价值依据时保留限制，不从近端上下沿补算或补造长期结论。字段、关键词或自审通过不代替实际正文验收。

report-review 和 run-advance --stage report 沿用原接口、report_basis、maintenance、information 和 provenance。layout 字段：

- `format=AUTHORED_REPORT_V1`；`body` 是完整的最终 Markdown，不使用插值，不拆 lead/blocks。
- `bindings` 是后台来源索引，不进入正文。每项 `{text,refs,scope}`：text 逐字存在于 body；refs 指向冻结已知标量，可引用带数字的分析句；scope 为 market/personal/clock。report_contract_revision=3 要求全部实质正文有来源归属、首个结论属公开市场，允许整段绑定及忠实改写；旧冻结契约按原接口恢复。归属声明不能证明语义或因果独立，不能为了绑定而照搬来源。
- `price_status={lower_spot,upper_short}`，沿用 VALID/ADJUSTED/REVIEW_REQUIRED/WITHDRAWN，程序不生成任何价位行。
- `quality_review` 使用本轮模板给出的键，契约4包含上述四项阅读验收，写本稿实际核对结果，不以字段齐全或“已检查”自证。旧冻结契约保留原键，不重写或重渲染历史。契约 3 的 `market_independence` 对照公开源命题及完整正文，包括最后概括，核验方向、同尺度拐点、证据链、公共价值和验证关系不依赖个人事实；个人选择有范围，旧混合报告不作为公共依据。错误贴标或引用不能支持原句时仍须修正。

revision 6/7 市场引用来自最终 market_result、metrics、public_evidence 或 report_subjects；revision 7 个人引用来自 portfolio_risk、strategy_advice、适用性和必要策略档位；revision 6 的 allocation_decision 仅用于原上下文恢复，不冒充新风险评估。result_binding 绑定最终市场、配置和适用性版本，不能混入内部分析或混合历史正文。旧版本按原公开字段恢复。必要数字等于冻结来源，不自动换算或舍入；派生值先经原证据流程核验并冻结，不强迫作者把阿拉伯数字改成中文绕过校验。

revision 8 的整体取舍尚未形成且确有报告适用性缺口时，LIMITED_FEEDBACK 可消费当前已评估风险与个人适用性限制，正文明确未完成范围及对动作的影响；必须绑定实际 applicability.portfolio.limitations，不消费旧机会建议、档位或新风险动作。该反馈不补造 investment_decision，不作为完整重评或建议续期；完整报告仍须消费已形成的总体选择，补评继续原研究。

价格绑定另带 `price={subject,unit}`。BTC 收盘引用 `/metrics/binance_spot_1h/latest/close`，subject=BTC、unit=USDT。产品价格只引用 `/report_subjects/QQQ/quote/price` 或对应 product_zones，subject=QQQ，unit 使用已核验来源的USD、USD/share或USDT；USD/share在正文写USD/股。指数区域在研究中保留 SPX/NDX 和原单位，不作为新正文价位；没有对应产品区域时不补造价格，影响当前安排时说明该限制，市场方向及风险判断继续保留。正文可用表头表达统一单位，只需绑定完整含单位的相关片段。

VALID/ADJUSTED 必须有有效正式来源；到期或待评为 REVIEW_REQUIRED；撤回为 WITHDRAWN。新稿不绑定失效或撤回档位重现为建议价格。历史原价留在历史产物中。EXECUTION_LIMITED 与 UNDETERMINED 对应 REVIEW_REQUIRED，不当作撤回或有效档位。无有效档位时，作者直接说明已经决定的安排或确实未决的范围，不自动追加占位行。

作者可将 evaluated_at 对应的 `/evaluation_time` 冻结字符串（日本时间）写作首行并绑定 clock；程序不插入时间。只有已绑定且逐字一致的首行评估时间可从重复比较中排除，不能排除正文行情日期或刷新市场时点。

冻结前先通读实际正文，再沿用现有 quality_review 核对：是否表达已完成的综合判断，依据是否支持结论，市场与个人安排是否对应，重要风险、有效性和必要限制是否准确，是否仍把因子裁决交给用户。逐段并逐句检查删去它会使哪项结论、关键依据、重要风险或行动被误解；没有实际损失就删除或合并。段落承担重要主题不证明其中每句话都必要；同时核对删改没有提高确认程度或改变安排。

reasoning 对照机制的应有响应、实际响应及反证裁决，核对方向、归因和延续的确认程度没有互换，不能以罗列冲突证明完整；cycle_basis/deep_report_summary 指出实际正文的总裁决、重要主题选择、未决动作影响和最后收束原句，逐项对照已形成结果，不能把方向句或条件清单当作选择，不要求所有内部字段进入正文。对照实际源句与正文核对各分句的主语和口径，以及交易所、具体产品身份和底层指数的证据归属；只确认未夸大为因果、资金净流或反转，不能证明证据范围没有扩大。phone_readability 对照最终正文说明实际删并的重复或过程信息、保留限制的具体作用；没有删改时也须核对句子必要性。不能用各段的主题清单、“短段落”“字段齐全”或“已检查”自证，指出删过哪些材料也不能为正文仍残留的噪音开脱。完整稿缺分析回原研究，表达缺项改本地 body，不补造判断或复活失效建议，也不让云端补写。程序测试与真实内容验收分开；分析、表达和完整正文消费默认对锁定真实数据复测并实际审阅，按[验收分流](runtime-maintenance.md#按问题选择验收证据)完成对应内容验收。真实送达及确需自然执行的项目另行核实，以实际收到的正文为准；自审或锁定复测不代替送达结果。

新契约7在新稿的每条市场绑定上核对直接带币安场所的 QQQ／VOO 产品称谓：`report_subjects` 必须有公开核验的产品身份，且该句必须绑定对应产品身份标量；仅有 SPX/NDX 底层引用不能支撑产品标签。未核验身份时可以继续报告底层盈利和方向，但须明确底层对象及对待核产品的有限含义。该结构校验只挡可判定的身份越界；同句因果、估值、推断强弱及全文上下文仍由模型实际审阅。历史冻结合同与已送达正文不重写。

新契约5在layout中加入reviewed_candidate_hash，绑定实际body、bindings、price_status以及稳定context_id和result_binding，不绑定滚动的执行时钟或审阅解释。先用run-advance --stage report --check-only输出完整候选及review_read，完整读取实际候选和来源后作上述语义审阅，再填写具体quality_review及返回的候选哈希并记录同稿；预检共用正式记录的确定性披露及 information 字面正文规则，按绑定 context 的事实代次和实际渲染正文提前检查；不证明全文语义通过，正式记录仍读取最新真实事实重新核验。独立研究的低层纯正文预览可不提供 action/information，scope 仅为 structure_and_bindings_only；正常报告 --check-only 要求 REPORT 并校验 information，声明报告元数据却缺项不能退回纯正文预览。正文、context、bindings、price_status、result_binding 与候选哈希均未变时，只纠正 information 索引可复用原实际全文审阅；正文或绑定变化仍须完整重审。任何缩写、重组、末尾或引用归属改变均使旧绑定失效，需要重新核验实际新全文，旧审阅不能沿用。程序不证明审阅意见正确，已知反例仍须由实际全文审阅识别。

兼容旧冻结契约3/4、已入队和UNKNOWN原稿，沿其原接口恢复，不补新字段、不重渲染历史。项目控制的定稿到交付路径保护逐字一致；外部聊天改写形成另一份文本，项目程序无法控制，不能借原稿的通过记录宣布该改写通过。

## 冻结、交付与去重

information 引用正文真实原句，内部检查与全部未决条件留在 maintenance。成稿审阅完成后再冻结。预览、source、artifact、发送请求中的正文及真实助手展示必须相同，新稿不经过旧渲染器。

文件末尾单个 LF 与会话正文之间的差异按传输格式处理，发送时省略该文件结束符。源稿、实际请求和助手回读各自保存原字节与哈希，回执区分 EXACT 与 TERMINAL_LF_ONLY；不使用 strip、折叠空格或重排 Markdown。正文内部换行、空格、数字、段落及附加内容仍须一致，多个末尾换行也不合并。历史未确认记录须重新核对原请求和同一助手正文后显式确认，不自动改变历史状态。

新稿采用 `VERBATIM`。enqueue/BEGIN 返回可直接发送的 request_body，必须完整发送该请求；云端禁止整理、润色、压缩、重排、补充说明、工具调用或重新分析。沿用 enqueue→BEGIN→真实发送→BIND_REQUEST→实际助手回读→CONFIRM。实际消息关联和完成状态仍须核验。

回读 review 保留 reviewer_role、agent_id、source_hash、display_hash、unresolved_issues，`bindings=[]`、`checks={}`；内容审阅已在冻结前完成，回读程序按上述文本边界核验，不启动第二遍语义分析。删句、改数、正文内部换行变化、重排或附加说明均不能计为成功，沿原一次更正与恢复链处理。不确定发送先恢复回读，不重复发送或重启研究。真实助手展示与系统通知分别验收。

去重以最后真实助手正文为准，作者先比较业务含义；时间、版式、措辞或内部哈希变化都不是新报告理由。程序拦截相同正文（仅剔除受控评估时间和纯 Markdown 样式），不代替模型同义判断。尚未展示的重要变化不能因上一小时已分析、同一版本或当天已报告而被屏蔽。每日最低反馈与用户明确重发沿原规则。

MARKET_MOBILE_V1/V2、MARKET_CONCISE_V1 及历史 V4/V5/V6 产物继续按原格式读取、恢复，不重渲染历史。旧 V2 的 lead/blocks、自动建议行、数字插值及 EDIT_ONCE 只用于这些历史路径，新入口不使用。


完整报告按重要资产和主题使用普通小节标题，各节结论先行，以自然段说明主导因果链和反证对结论的实际作用。标题按内容选取，不将五模块或内部字段机械翻成栏目。个人应用集中、去重；长期资产用途不等于当前存量可维持，动作级未知明确影响哪个决定。内部生命周期字段、验证编号、运行信息与工程结果留在证据产物，不灌入用户报告。
