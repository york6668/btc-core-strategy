# 综合研判报告与原文交付

新稿使用 `AUTHORED_REPORT_V1`。模型先完成正式研究、本轮公开市场观察及个人适配中的综合判断，再用 `body` 表达已经形成的结果；程序校验来源、数值、单位、期限及建议有效性，返回同一正文。本文件统一维护研判与用户报告的职责边界；研究方法由[核心策略](core-strategy.md)拥有，报告必要性见[报告复核](report-care.md)。

## 研判与报告的职责边界

正文开头承接框架识别的当前周期状态（中性／向上／向下）和主导依据，随后说明参与价值、周期内重要风险与必要应对；周期不是天数或周数。观察窗口和有效期限只服务对应判断。日内数据在实质影响这些含义时进入正文，普通反弹、回收、破位及短线剩余期限不能挤占主结论。重大即时风险仍及时报告并说明影响范围。周期分析缺失时回到原研究修正，不能在成稿时延长预测窗口。

当前方向与日期用途分别表达：机制检验期到某日，不应缩写为该状态将延续到某日。需要提及日期时，按原结果说明它是检验、有效还是兑现窗口；可以自然分句或在句内交代用途，不规定固定句式，不要求展示全部内部期限。有依据的前瞻延续判断仍按原条件、期限和确认程度表达，不能一律降为观察窗口，也不禁用“至”等字词。源稿措辞含混时对照当前结构、依据和 `forward` 的时间依据澄清，忠实承接含义不等于照搬歧义；实质判断不明则回原研究，已发送历史不改写。

承接已形成的动量与趋势判断，清楚回答当前到哪一步、依据、相较上次的实质变化与下一项鉴别性验证。原方向动力减弱、相反趋势形成和反转失败保持确认差别；短暂反弹不升级为趋势，具体证据缺口不改写成中性。只表达实际研究结果，不新增推断或机械栏目；价格风险收益、等待价值和个人风险仍保留各自结论。缺分析返回原研判，不能靠补上“枯竭／反转”等词语补齐。

完整分析由模型持有并持续维护：核验证据、去除重复支持、选择与权衡因子、比较竞争解释、判断周期关系，并裁决反证和未知对结论的实际影响。完整报告向用户交付这些工作形成的方向、适用周期、依据与个人应对；内部分析覆盖范围不等于正文必展示清单。既有 factor_assessment、outlook、研究结果与 maintenance 继续承载完整依据、未决问题及复核条件，新稿通过[revision 7 完整闭环](closed-loop.md)的最终结果接口消费研究，完整分析保留内部。

报告直接说明本轮综合判断，并解释主导因素如何支持它。不同周期的关系先由模型判断清楚，实际影响当前决策时再呈现；不能并列冲突信号或只写“尚未证伪”“仍有冲突”“等待确认”，让用户重新完成因子取舍。明确表达自己的判断不等于保证未来结果，也不允许把 PARTIAL、UNKNOWN 或未确认事实改写成已确认；证据不足的具体范围及其影响由模型判断，仍给出有依据的方向与有边界的安排。

依据展开到足以解释主导判断，每段及段内每句话都应帮助理解方向、关键依据或行动。重要反证进入正文时，直接说明它为何改变或没有改变当前判断；条件、未知、数据时点和产品限制用它对方向、风险、数量或行动的具体影响表达。同一动作或限制在最合适的位置充分说明一次，开头结论与个人安排不要重复整句。来源核验过程、重复否定、完整未知清单和内部调度留在研究及维护材料。涉及执行有效性、重要风险或重要事实纠错的内容必须保留，不能以去噪掩盖。条件是否成立及是否需要调整继续由模型维护；已对外承诺失约或建议失效时，简明说明实际影响和补救，不把取证、适配及运行过程展开成报告。

内部规则用于约束判断和动作，不自动成为正文。只有当前表达可能造成具体误解时，才说明相应边界；没有提出跨资产调整，就不例行附上各资产独立判断的规则。必要限制直接落到结果，例如产品资料未确认时说明无法给出可靠产品交易价，不罗列接口、历史行或核验步骤；保护风险尚未核清时说明为何暂不能决定是否调整或调整多少，不逐项抄录未知字段。上述是信息取舍方法，不是固定句式；未变化但仍会影响当前理解或执行的重要风险仍应保留。

`next_observation`、`maintenance.recheck_at`及例行运行时间属于内部接续，不是正文必备结尾。例行复核按时或提前完成只记维护，正文交付其形成的实际判断；重要市场事件的时间、建议有效期及用户明确询问的进度按实际影响说明。旧稿已对外承诺的期限继续履行，但不因曾写过就逐轮重述或新增下一时刻承诺；确有失约或建议失效，仍简明说明影响与补救。

汇报不拥有第二次研判权。Sol、其他模型、程序和云端都不能为了摘要、整理、数字绑定或交付重新排列因子优先级、另立因果解释、改变方向及建议。Sol 在既有职责内先完成小时核验及适用性判断，已核验的重要市场更新和风险仍可按原接口及时报告；需要改变正式解释、周期或建议时返回原研究。成稿只表达已形成的判断及其依据，措辞整理不产生新判断；冻结后按原文交付。

新数据、新冲突或未知解除先判断对结论、风险和安排的净影响，不自动成为报告理由。实质变化、重要事实纠错及每日最低反馈沿用原规则；尚未展示但不改变这些含义的内部发现不要求向用户逐项汇报。

## 内容和表达

用户报告对象是**币安 QQQ、VOO，以及 BTC**，从研究与观察输入就明确。SPX/NDX 保留为底层市场研究、历史记录和引用身份，不强制成为报告标题。价格采用美元近似口径，股票USD/股与合约USDT均可展示，保留实际单位和产品身份；底层指数点位仅留在研究中。具体产品身份与价格见[币安美股产品](equity-products.md)。组合仍是持续决策单位，名称调整不改变成分、比例或真实持仓。

各市场给出综合方向及适用周期，依据围绕这个判断展开。结构变化、周期共振或反转、确认程度在改变当前理解或安排时说明，不机械复制全部 horizon 字段或排列状态标签。评级未变不代表风险含义未变；缺证不写中性。不同市场的独立结论不能被合并抹平，也不要求把每个内部分析期限变成正文的一条结论。

市场判断先独立形成，再交付个人资产风险结论与实际组合影响，仅风险需要应对时附建议。风险结论可以独立成立，总资金与占用比只是可选依据，不从短线偏弱、比例偏离或缺数直接生成操作，不重复分析，不按五模块或逐资产固定拆分，持仓不能反向改变市场结论。分歧区状态和双向风险在内部完整维护；正文按当前判断需要给出重要区域、风险及改变条件，不强制单列分歧区或逐项展开双方路径。观察区触及不自动成为交易建议，小时变化不擅自升级为中期反转。按实际内容使用加粗结论、短段、列表或表格，让市场判断和个人应对容易找到；不设固定长度、段数或栏目，版式不能代替信息取舍。预览只作表达回归样本，不固化后续方向、周期、价位或栏目模板；预览清晰不证明后续自动成稿达标。

前瞻中的价格吸引力、美债机会成本及风险补偿承接已完成研判。已形成且影响当前取舍的比较结论在正文保留：相对美债等待，现价承担新增风险的补偿是否充分或仍无法确认、主要原因及改变条件；方向偏多或偏弱、笼统的资金成本不能替代这一判断。数值或表格按理解需要展示，不固定年份、利率或溢价档位；精简计算细节时保留比较结论，不能只在内部维护中记录。情景回报、达到要求回报的门槛与预测价格保持原有区别，成本锚保留对应群体及估计属性；缺少量化依据时承接已有定性判断及影响结论的具体限制，成稿不补算或重估。若最终市场结果遗漏研究中已经形成的重要比较，先在市场阶段忠实承接并冻结，再生成正文，不让成稿阶段从因子材料重建判断。

依据日期、未完成K线、休市和正式行缺失在影响判断时保留，合并同一限制。现金、保证金等未知须区分数量限制和动作本身无法决定，不能反向改写公开市场方向，也不要求每份报告重复列出全部账户未知。如需要事实同步，只提醒实际仓位已变化时同步，未变化无需操作。

完整稿缺少重要分析时沿原研究补齐；表达缺项在本地成稿阶段修正。格式维护本身不触发完整重评。新正式建议须经原深评采纳，报告不得提高确认程度或补造价位。到期不自动延长，撤回价格不从历史恢复。

## 最终正文接口

现有 `cycle_basis`、`deep_report_summary` 同时核对当前周期状态是否从市场结果贯穿正文、主导依据是否支持该判断，以及局部价格风险是否被误当周期价值；对照实际措辞说明当前方向与日期用途是否分清，日期未变不能证明含义未变。报告只承接已形成的同期限风险补偿判断；缺少周期价值依据时保留限制，不从近端上下沿补算或补造长期结论。字段、关键词或自审通过不代替实际正文验收。

report-review 和 run-advance --stage report 沿用原接口、report_basis、maintenance、information 和 provenance。layout 字段：

- `format=AUTHORED_REPORT_V1`；`body` 是完整的最终 Markdown，不使用插值，不拆 lead/blocks。
- `bindings` 是后台来源索引，不进入正文。每项 `{text,refs,scope}`：text 逐字存在于 body；refs 指向冻结已知标量，可引用带数字的分析句；scope 为 market/personal/clock。不能为了绑定数字而整段照搬来源。
- `price_status={lower_spot,upper_short}`，沿用 VALID/ADJUSTED/REVIEW_REQUIRED/WITHDRAWN，程序不生成任何价位行。
- `quality_review` 使用本轮模板给出的键，写本稿实际核对结果，不以字段齐全或“已检查”自证。

revision 6/7 市场引用来自最终 market_result、metrics、public_evidence 或 report_subjects；revision 7 个人引用来自 portfolio_risk、strategy_advice、适用性和必要策略档位；revision 6 的 allocation_decision 仅用于原上下文恢复，不冒充新风险评估。result_binding 绑定最终市场、配置和适用性版本，不能混入内部分析或混合历史正文。旧版本按原公开字段恢复。必要数字等于冻结来源，不自动换算或舍入；派生值先经原证据流程核验并冻结，不强迫作者把阿拉伯数字改成中文绕过校验。

价格绑定另带 `price={subject,unit}`。BTC 收盘引用 `/metrics/binance_spot_1h/latest/close`，subject=BTC、unit=USDT。产品价格只引用 `/report_subjects/QQQ/quote/price` 或对应 product_zones，subject=QQQ，unit 使用已核验来源的USD、USD/share或USDT；USD/share在正文写USD/股。指数区域在研究中保留 SPX/NDX 和原单位，不作为新正文价位；没有对应产品区域时不补造价格，影响当前安排时说明该限制，市场方向及风险判断继续保留。正文可用表头表达统一单位，只需绑定完整含单位的相关片段。

VALID/ADJUSTED 必须有有效正式来源；到期或待评为 REVIEW_REQUIRED；撤回为 WITHDRAWN。新稿不绑定失效或撤回档位重现为建议价格。历史原价留在历史产物中。EXECUTION_LIMITED 与 UNDETERMINED 对应 REVIEW_REQUIRED，不当作撤回或有效档位。无有效档位时，作者直接说明已经决定的安排或确实未决的范围，不自动追加占位行。

作者可将 evaluated_at 对应的 `/evaluation_time` 冻结字符串（日本时间）写作首行并绑定 clock；程序不插入时间。只有已绑定且逐字一致的首行评估时间可从重复比较中排除，不能排除正文行情日期或刷新市场时点。

冻结前先通读实际正文，再沿用现有 quality_review 核对：是否表达已完成的综合判断，依据是否支持结论，市场与个人安排是否对应，重要风险、有效性和必要限制是否准确，是否仍把因子裁决交给用户。逐段并逐句检查删去它会使哪项结论、关键依据、重要风险或行动被误解；没有实际损失就删除或合并。段落承担重要主题不证明其中每句话都必要；同时核对删改没有提高确认程度或改变安排。

reasoning 核对主导解释及反证的实际影响，不能以罗列冲突证明完整；cycle_basis/deep_report_summary 核对忠实承接及必要信息，不要求所有内部字段进入正文。phone_readability 对照最终正文说明实际删并的重复或过程信息、保留限制的具体作用；没有删改时也须核对句子必要性。不能用各段的主题清单、“短段落”“字段齐全”或“已检查”自证，指出删过哪些材料也不能为正文仍残留的噪音开脱。完整稿缺分析回原研究，表达缺项改本地 body，不补造判断或复活失效建议，也不让云端补写。程序测试、同稿表达回归和下一次自然报告分别验收；自然报告以实际收到的正文是否清楚交付判断和安排为准，自审文字不代替该结果。

## 冻结、交付与去重

information 引用正文真实原句，内部检查与全部未决条件留在 maintenance。成稿审阅完成后再冻结。预览、source、artifact、发送请求中的正文及真实助手展示必须相同，新稿不经过旧渲染器。

新稿采用 `VERBATIM`。enqueue/BEGIN 返回可直接发送的 request_body，必须完整发送该请求；云端禁止整理、润色、压缩、重排、补充说明、工具调用或重新分析。沿用 enqueue→BEGIN→真实发送→BIND_REQUEST→实际助手回读→CONFIRM。实际消息关联和完成状态仍须核验。

回读 review 保留 reviewer_role、agent_id、source_hash、display_hash、unresolved_issues，`bindings=[]`、`checks={}`；内容审阅已在冻结前完成，回读程序逐字核验，不启动第二遍语义分析。任何删句、改数、换行变化、重排或附加说明均不能计为成功，沿原一次更正与恢复链处理。不确定发送先恢复回读，不重复发送或重启研究。真实助手展示与系统通知分别验收。

去重以最后真实助手正文为准，作者先比较业务含义；时间、版式、措辞或内部哈希变化都不是新报告理由。程序拦截相同正文（仅剔除受控评估时间和纯 Markdown 样式），不代替模型同义判断。尚未展示的重要变化不能因上一小时已分析、同一版本或当天已报告而被屏蔽。每日最低反馈与用户明确重发沿原规则。

MARKET_MOBILE_V1/V2、MARKET_CONCISE_V1 及历史 V4/V5/V6 产物继续按原格式读取、恢复，不重渲染历史。旧 V2 的 lead/blocks、自动建议行、数字插值及 EDIT_ONCE 只用于这些历史路径，新入口不使用。
