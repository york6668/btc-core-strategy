# 判断生命周期与术语契约

目标是持续识别有据可检验的机制主线、周期方向与拐点、当前价格的参与价值，再单向下游适配个人。无足够优势和证据不足可以是完整结论；报告完成不证明研究成功。本契约统一核心策略、独立研究、实际审阅、持续对象和报告的含义，不建立固定指标、必填十栏或交易系统。

## 定义及适用边界

事实是可追溯来源在明确时间和范围内的陈述或观测；来源如何描述，与系统如何解释分别保存。预测、因果解释和量化估计仍是推断。旧研究和连续上下文属于带版本的历史判断，必须对照外部证据复核。CFA 的[事实与意见及重大限制](https://www.cfainstitute.org/standards/professionals/code-ethics-standards/standards-of-practice-v-b)支持这一边界；本项目不以引用存在代替语义核验。

主线是竞争解释中有传导机制、应有响应及实际反证检验的解释，不等同一段价格走势，也不要求唯一原因。方向、归因、延续及参与价值可以有不同支持程度。自己的预期、可观察的市场预期及现价已经反映多少分别论证；消息广为人知不证明完全计价，利好兑现不保证超额回报。

采样粒度、回看期、研究结构尺度、判断适用期限、兑现窗口、复核时点分别维护。周期表示当前向上、中性或向下，UNKNOWN 不转写中性。依据问题与完整结构选择尺度，不固定四小时、周数或 ETF 门槛；长期机制要有可检验中间预期，不能以无限延期免除原期限复核。[Fidelity 的趋势尺度](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/basic-concepts-trend)提供行业背景，具体划分与核验条件是本项目方法约定。

价格动量与趋势方向不同；驱动力衰减、结构受损、相反方向形成、持续确认是不同命题。反向变化或动量背离是可检验证据，不能直接证明同尺度反转，旧趋势结束也可能进入震荡。[Fidelity 动量定义及背离限制](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/momentum)不提供本系统必须采用的统一阈值。跨尺度联系须有实际结构与传导说明。确认表示所述证据条件已满足，不表示未来保证。

价值由可信兑现路径、当前价格与隐含预期、风险及净成本共同评价，分别说明条件价值与潜在回报补偿。企业质量、趋势、支撑或相对旧高点的跌幅不是估值结论。[CFA 的估计价值与市场价格](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/equity-valuation-concepts-basic-tools)针对股票估值；BTC 不直接套公司现金流。锚不足时允许相对或条件情景、定性结论及具体未知，不能捏造终值。

证据可信度、方法确认程度与事件概率分开；概率说明事件、期限、条件及估计依据，未校准信念不能冒充历史频率。非互斥穷尽的情景不强凑概率总和。[Morgan Stanley 对概率、可信度与反馈的区分](https://www.morganstanley.com/im/publication/insights/articles/article_probabilitiesandpayoffs.pdf)是行业依据；缺乏可辩护估计时不数字化是本项目约定，不伪造精确性。

独立市场价值、具体产品适用性和个人行动分别判断。同问题、尺度、证据与方法下，仓位成本盈亏和偏好不改市场结论；个人用途可以改变所问问题或期限，但须明示新问题，不能偷偷改答案。产品缺口只限制对应载体、价位或净回报；个人文件缺失只限制对应个人分支，不代表零仓、安全或无须应对。行业背景见 CFA 的[独立性](https://www.cfainstitute.org/standards/professionals/code-ethics-standards/standards-of-practice-i-b)及[适用性](https://www.cfainstitute.org/standards/professionals/code-ethics-standards/standards-of-practice-iii-c)。

判断质量的比较基线与收益基准分开；收益比较事前明确适当基准、币种、期限、风险和回报口径。费用、价差、滑点、融资及产品成本缺失不按零；流动性包含能否在合理成本下及时退出。[CFA 绩效评价](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/portfolio-performance-evaluation)区分计量、归因与评价。本项目在没有完整数据时不编造净收益或策略绩效。

## 实际控制与版本接续

问题 → 当时可知证据 → 竞争假设及反证 → 独立判断 → 实质审阅与正式采用 → 个人适配与报告 → 后续事实 → 复核、修订或撤回。已有 issue/request、市场及期限对象、REVIEW、正式指针和不可变证据继续承担这些关系；问题身份和尺度在已有对象的 period/basis/forward 与业务 payload 中明确，不另造结论 Owner。消费者按实际 version/digest 引用；候选、正式结果和历史各自保持角色。

新事实、来源修订、结构变化和预期偏离触发相关复核，也检查尚未登记的新关系。因素及假设明确采用、继续观察或退出的意图、证据和理由；未再提及不等于删除。退出通过原对象及 expected_version、有据 change_reason/dependencies、active=false 保存历史并影响消费者；已退休对象不自动复活；重新采用须实质审阅后建立新的相关对象身份，并明确关联被替代对象与理由；原问题或 issue 身份可继续，原退休对象及历史不重启。维持旧观点仍需实际检验，撤回理由与新论点分别保存。

催化更新信息，证伪针对关键机制或预测，个人现金或风险约束只改变个人行动；催化延迟可能否定时间预期而未否定长期机制。原期限到期沿原 REVIEW 评价，不能以 PENDING、EVIDENCE_LIMITED 或延期冒充完成。

每轮读取固定公开快照和对应原始证据；服务连续上下文按 run.created_at 的已知版本冻结，之后读取或恢复不重写为后来状态。未绑定的旧动态索引保留原字节，另以不可变版本重建当时可知视图，并标明它是重建材料而非原轮次已冻结输入。观察事件截止与资料获知截止分别说明。操作记录实际方法发布和执行服务字节；恢复保留原执行组合，同时记录当前恢复组合，不能宣称它们天然相同。数据与 reader 身份依真实冻结输入及部署读回核验，未知不从方法版本猜测。跨节点分工不允许未经核验补用另一节点数据。

## 验证及纠错

工程行为、分析语义、历史效果、个人执行分别验收。历史情景、模拟、锁定数据的事后回归和前瞻验证分别标记；反复调过的样本不再算独立，模型历史知识及获知时间泄漏边界如实披露。[CFA 回测与模拟](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/backtesting-and-simulation)提供方法背景，不证明本项目已有绩效回测平台。

后续分别评价方向、机制、拐点识别早晚及误漏报、价值兑现；未触发、未到期、缺数据单列。按数据、推理、尺度、适用性、个人映射或表达定位错误，修订方法并比较改善与退化，保留失败版本。一次盈亏不自动证明过程或触发调权；后续冻结验证不阻断已确认缺陷的当前复测。报告只保真压缩，不重新形成方向、估值或因果裁决。
