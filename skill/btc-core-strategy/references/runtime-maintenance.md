# 自动任务运行维护

完整分析、条件核验、必要研究、及时反馈和真实送达是降耗的前提。调用次数、报告篇数或测试通过不能代替这些结果，降耗指标不是研究次数或每轮运行上限。

## 日检查与三日自然验收

用量读取是对当前 Codex 内部结构的只读适配，不以某个 `state_N.sqlite` 名称作为长期接口。优先显式 `--db`，其次节点 `codex_state_db`；配置文件消失时，仅唯一且结构兼容的发现结果可使用，不按编号或修改时间猜选。返回 `source.status=UNAVAILABLE` 表示统计缺口，数值与达标情况保持未知，不更新为已统计，不阻断市场分析。已有原生接口能提供同等明细时可替代此适配，但账户额度百分比不能代替任务用量。

沿用原任务及原缺陷目录：`<本地既有缺陷目录>/`。缺陷为 `defect.json`，历史冻结比较基线为 `baseline-usage-including-descendants.json`。小时运行先使用：

```sh
$BTC_PYTHON $BTC_RELEASE/skill/btc-core-strategy/scripts/run_usage.py --status --defect <本地既有缺陷目录>/defect.json
```

`--status` 只读且只返回上一完整日本自然日的待办与当前自然验收窗口，不展开历史。`usage_due=true` 时，按返回的 since/until/usage_output 调用同一脚本的 `--since`、`--until`、`--output`，加 `--baseline` 与 `--defect` 的上述路径。`quality_and_delivery_review_due=true` 时，核对代表性实际分析、必要研究与反馈、当日真实送达和未解决错误，在原 natural_acceptance.reviewed_days 简短追加该日证据及缺口。统计已完成但质量未核验时只补质量，不重复统计。

用量保留原任务、子代理及失败/未完成消耗；缓存已包含在输入中，不重复相加、不换算订阅额度。绝对目标为普通运行模型往返中位数不超过14；同类模型/effort/运行分组与冻结基线下降至少50%独立检查。跨模型缺少可比基线时相对项为未知，不冒充同类达标，也不能掩盖绝对目标失败。嵌套执行错误与非零退出按实际工具输出定位，同一次调用相同错误只计一次；未检测到错误不证明没有错误。

run_usage 同时按普通嗅探、深评及报告交付分组输出 elapsed_seconds 和 repeated_errors 的中位数、p95 与已知样本数。整轮耗时取主任务及子代理的实际起止跨度，不相加重叠代理时长；缺少时间或未完成保持未知。工程调试与普通自然运行分开，隔离材料缩减和程序测试不证明自然耗时目标已经达成。

本次切换的三个完整日本自然日在原 natural_acceptance.requirements_first_change 内记录，与旧失败窗口分开。逐日确认分析完整性、必要研究和报告、真实每日送达、重复错误与用量。三日完成后汇总同类比较；未发生的研究或恢复场景只声明隔离验证。缺少可比证据、存在未解决复发或质量/送达不足时保留未验收，不能关闭缺陷。脚本只补用量证据，未知或单日通过都不清除原失败，关闭仍需完整独立验收。

## 当前接续与恢复

原自动任务的 memory.md 只保存当前未完成工程事项、正式状态入口和历史引用；需要更新时改写当前接续段，不逐小时追加流水账。旧全文归档在同一自动任务目录的 history 下，只有具体恢复问题需要时才读取。它不是资产事实、策略或送达状态的来源，不保存个人账户明细。

先依据正式研究进度和真实运行核对在办研究，再从已完成阶段接续；不能把 NOT_CHECKED 当作空闲，也不在原主运行仍取证、映射或发布时重复派生研究。同一错误没有新诊断不原样重试或重开研究。交付不确定按原发送尝试回读，不能用重新研究或重发解决绑定异常。

运行入口回退使用切换前保留的代码和提示词；已完成正式版本、观察、研究与真实交付继续有效，不能连同恢复副本回滚这些结果。工程问题保留本地，不进入云端投资报告。沿用原调度、模型、目的地和仅失败通知，不新增监控任务；宿主限制仍如实标为 SELECTIVE_NOTIFICATION_UNSUPPORTED。

## 按问题选择验收证据

分析、证据推断、策略表达与手机正文的修正，默认沿原研究及报告消费链对锁定真实数据复测。实际审阅上游证据、完整判断和最终正文，覆盖本次受影响场景；满足问题范围即可完成内容验收，不以另有自然报告为前置。原材料不能支持的具体判断仍保持未验证，补证按该判断的实际需要决定。合成测试、字段齐全或自评通过不代替这项实际复核。

锁定复测保留原输入身份、取得时间及当时可知边界，事后复核不冒充前瞻验证、盲测或全新独立研究，也不自动证明生产采纳或真实送达。调度、真实采集、实际采纳、发送与回读、自然耗时与成本，以及特定前瞻或后继条件，按问题所需的实际执行证据验收；已有证据可以复用，只有确需自然发生的部分才保留对应 natural_gap，并说明具体依赖。该缺口不扩成已通过内容的缺口。保留原缺陷身份、观察窗口和其他待办，不默改或延长窗口；关闭接口继续使用 preserve_window=true。

## 资产风险纠偏的持续验收

本项接入现有 BTC核心策略自动重评 的正常运行和日检查，复用节点 acceptance-checks 中该项及现有 acceptance.defect 身份，归属 personal_allocation、report_delivery。任务 memory 只保留当前待办入口，不保存资产明细或逐小时流水。待办记录已发布版本、本机实际生效时间、新风险结果实际采纳时间、原报告本地引用，以及真实复测、运行证据和仍缺的具体依赖；仅部署成功不能填写采纳或送达完成。

正常小时评估复用本轮证据，不额外发起验收研究。每日查看新版本实际输入、风险结论、必要报告和真实回读，分别核对：无风险需要应对时结论完整且不凑动作；风险需要应对时有清楚依据和简明建议，操作未决不编造；信息不足时说明具体判断边界，不默认安全、不制造比例或条件链。原有机会分析与市场冻结仍有效。原报告仅留在本机供回归，不复制到源码或长期记忆。

分析与表达按上述验收分流使用锁定真实数据复测，实际风险结论与完整报告消费审阅通过即可完成对应内容验收。确需实际运行的依赖按项保留缺口，回放不冒充真实采纳、送达或自然运行通过。发现复发接续同一项；调用 acceptance.repair 只关闭证据已满足其实际范围的缺陷，指定 preserve_window=true，保留原全局窗口、其他待办和历史；不得仅凭安装、合成测试或未经实际审阅的回放关闭。完成后将本地项标为完成，后续小时不重复处理。没有新进展不重复通知，验收进度不例行附入投资报告。

## 周期报告纠偏的持续验收

沿用现有 BTC核心策略自动重评、小时频率、模型分工、报告目的地和通知设置。节点 acceptance-checks 中登记本项，关联现有验收类别 research_corrections、forward_outcomes、report_delivery；不重置全局窗口或其他待办。项内区分已发布版本、实际生效、修正结果采纳、更正报告送达、锁定复测覆盖、实际运行依赖及缺口，保存原报告和真实运行的本地引用。源码只保存方法和测试构造，实际报告、账户、验收状态及运行证据留在节点；任务 memory 仅保留当前待办入口。

每轮先查看本项是否未完成，复用正常研究、观察、正式结果和必要报告的真实输出；有新的相关结果才补本地证据，每日复核一次新增证据，不重复扫描已审阅内容。核对实际输入如何支持主要投资周期、主情景和summary如何正式采纳、最终正文如何消费，以及真实助手回读是否相同。按问题判断内容，不以标题出现“周期”、字段齐全、正文哈希一致或自评通过代替质量审阅。当前用户纠偏可以立即作用于在办研究，但保留其原物理代码、研究请求、代理和已完成阶段；不为方法修订虚构程序兼容映射。

内容场景可用锁定真实材料分别复测：日内方向反复而周期依据未变时，主结论一致且没有无据动作；机制或累计反证改变时及时修正而不必等破位；周期证据不足时保留具体限制而不以小时判断替代；重大即时风险及时表达且不冒称周期反转；更正研究、正式结果和最终正文保持同一投资周期身份；实际采纳、送达与后继验证按本次问题所需另行核实。近端价格空间不得冒充周期价值或收益上限，同期限美债比较仍须有对应情景依据。个人风险与机会建议各自保持原边界。

分析与表达默认按上述验收分流使用锁定真实数据复测；完整源判断与最终正文已实际审阅时，不因缺少后续自然报告保留内容消费缺口。锁定材料未覆盖的具体判断仍未验证，确需自然运行的项说明依赖并保留对应 natural_gap；事后复测不当作前瞻结果。仅测试、安装成功、运行次数或时间到期不能完成内容验收。不为验收增加研究、凑报告或重发 UNKNOWN；用户已经要求的更正研究及必要更正报告正常执行。发现复发接续同一项，保存受影响证据，修正对应环节后继续验证；已确认的其他场景和历史不清空。

本次所需内容场景与完整报告消费在锁定真实数据上复测并实际审阅通过后，可完成对应内容验收。实际运行依赖只影响对应项，不把等待自然输出设为内容修正的统一前置。绑定实际发布和审阅证据调用 acceptance.repair 时，只关闭证据已满足其实际范围的缺陷，指定 preserve_window=true；未验证的真实采纳、送达、前瞻结果及其他运行待办仍按原身份保留。已完成项后续小时跳过专项，原定时业务、窗口及其他待办继续。没有新增进展保持安静；重要失败、需用户处理的缺口或完成只反馈一次，工程验收不例行附入投资报告，也不冒充整个节点或其他缺陷已验收。
